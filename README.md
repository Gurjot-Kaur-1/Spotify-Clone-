# Spotify Clone 🎧

I made this project to try and recreate the Spotify web player UI using HTML, CSS and JavaScript.  
Right now it mainly focuses on the design and layout part.

## What’s in it
- Spotify-like layout  
- Basic structure of a music player  
- Responsive design (works on different screen sizes)

- HTML

- JavaScript
